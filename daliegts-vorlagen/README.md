# DaLiegt’s – Vorlagen-Katalog

Gemeinsame Sammlung von **Möbel- und Magazinvorlagen** für [DaLiegt’s](https://daliegts.de): Sortimentskästen (Parkside, Stanley, raaco,
Allit, Würth …), Regale und Schränke mit Fachraster und Maßen.

In DaLiegt’s unter **Lagerorte › Vorlagen › „Weitere Vorlagen aus dem Katalog holen …“** werden diese Vorlagen angezeigt und lassen sich
mit einem Klick übernehmen. Danach die Vorlage anklicken und die Vorschau auf einen Ort ziehen – fertig ist das Möbel mit allen Fächern.

Der Katalog ist die Datei [`index.json`](index.json). Sie wird automatisch aus den Dateien in [`templates/`](templates) gebaut.

## Eigene Vorlage beitragen

1. In DaLiegt’s die Vorlage anlegen (Lagermöbel-Assistent oder „Als Vorlage speichern“) und in der Vorschau auf **JSON-Export** klicken.
2. Die Datei hier unter `templates/` hochladen (Add file › Upload files), Name z. B. `parkside-33-schubladen.json`, und einen Pull Request erstellen.
3. Ein automatischer Check prüft das Format. Sobald die Vorlage übernommen ist, erscheint sie bei allen im Katalog.
